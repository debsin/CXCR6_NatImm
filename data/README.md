# Data availability

No study data are stored in this repository.

The curated analyses use public or controlled-access resources associated with the Nature Immunology study and external validation datasets. Key sources include:

- mouse single-cell sequencing: ENA accession `PRJEB52332`;
- COVID-19 bronchoalveolar lavage single-cell data: `GSE145926`;
- BCG-trained immunity data: `GSE124218` / `GSE124220`;
- human tissue-resident T-cell reference datasets, including `GSE111898` and `GSE83637`;
- human lung-tumor TRM data: `EGAS00001004707` (controlled access);
- TCGA cancer RNA-seq and survival data, obtained through GDC/UCSC Xena;
- source-data files distributed with the Nature Immunology article.

For the study's official mouse scRNA-seq/TCR-seq code release, see:

- GitLab: https://gitlab.univ-nantes.fr/gourain-v-1/cxcr6_lungsepsis
- Zenodo: https://doi.org/10.5281/zenodo.10715057

This repository does not duplicate RDS files, TCGA matrices, patient-level data, EGA-controlled files or publisher spreadsheets.
